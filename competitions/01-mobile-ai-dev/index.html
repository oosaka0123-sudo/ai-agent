📱 あなたのスマホ
↓
🧠 Claude Code / Jules / Codex が実装
↓
🐙 GitHub = 共通の記憶・作業場所
↓
🛡️ GitHub Copilot = 監督・PRレビュー・競合確認
↓
⚙️ GPT / Actions = 統合・テスト・マージ・デプロイ
↓
🌐 GitHub Pagesで公開
