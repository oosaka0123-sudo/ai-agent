SUPERVISOR / REVIEWER

GitHub Copilot

このシステムでは、CopilotをClaude Code・Google Jules・OpenAI Codexと同じ「実装担当」として並べるのではなく、基本は監督・レビュー・統合支援役として使います。

Copilotの役割

3AIの仕事をGitHub上で見張る

  • Pull Requestのレビュー
  • 仕様違反・セキュリティ・スマホUXの確認
  • 古いブランチと最新mainの差を確認
  • 競合・重複作業の発見
  • 統合方針の提案と小規模修正

チーム全体の流れ

📱 ユーザーが目的を指示
↓
🧠 Claude Code / Jules / Codex が専用ブランチで実装
↓
🐙 GitHubへPRを集約
↓
🛡️ GitHub Copilotがレビュー・競合確認・統合支援
↓
🤖 GPTがGitHub操作・統合・Actions・Pages公開を可能な範囲で完遂

実装もできる？

できます。 明示的に開発タスクを割り当てればCopilot自身も実装できます。ただし通常運用では、Claude Code・Jules・Codexと同じ仕事を重複させず、レビュー役を優先します。

現在の4AI体制

Claude Code：実装
Google Jules：独立実装・比較
OpenAI Codex：実装
GitHub Copilot：監督・レビュー・統合支援
