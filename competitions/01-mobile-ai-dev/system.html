このシステムとは

スマホを司令塔にして、Claude Code・Google Jules・OpenAI CodexをGitHub上で並列運用するAIエージェント開発基盤です。1つのAIに全部を任せるのではなく、3つの頭脳を競わせたり、役割分担させたりして開発します。

全体構成

📱 スマホ：指示・確認・最終判断
↓
🧠 Claude Code　｜　Google Jules　｜　OpenAI Codex
↓
🐙 GitHub：仕様・コード・ログ・PR・履歴を保存する共通記憶
↓
⚙️ GitHub Actions：テスト・検証・デプロイ
↓
🌐 GitHub Pages / PWA / API / 自動化へ展開

2つの使い方

競争モード

同じ課題を3AIへ一斉に投げ、それぞれ独立に作らせます。設計・文章・UI・コード・テスト方法まで比較し、最も良い部分を採用します。

チームモード

調査、設計、実装、レビュー、テストなどをAIごとに分担します。1つのAIが詰まっても別のAIが補えるため、止まりにくい開発になります。

GitHubが「記憶」になる

AI同士は会話履歴を直接共有できません。そこでREADME、AGENTS.md、PROJECT_SPEC、コード、コミット、PR、開発ログをGitHubに残します。次のAIはGitHubを読んで続きを理解できるため、会話をまたいでもプロジェクトを継続できます。

基本の流れ

スマホから目的を指示「何を作るか」を決める。
3AIへ一斉投入または役割分担競争かチームかを選ぶ。
各AIが専用ブランチで作業実装・テスト・自己レビューまで行う。
GitHubでPRとして集約成果と差分を見比べる。
GPTがGitHub運用を仕上げる可能な範囲で統合・マージ・Actions・Pages公開まで進める。
完成物を公開・次の開発へWeb、PWA、API、自動化などへ展開。

この仕組みの狙い

PCの前に張り付かない開発

スマホで指示と判断を行い、重い実装作業はクラウド上のAIエージェントに任せます。GitHubを中心にすることで、複数AIが同じ資産を扱えるようにします。

AIを「チャット相手」ではなく「開発チーム」にする

単発の質問で終わらず、仕様・履歴・成果物を蓄積し、次の作業へつなげることがこのシステムの中心です。
