このシステムとは

スマホを司令塔にして、Claude Code・Google Jules・OpenAI Codexの3AIを実装担当として動かし、GitHub Copilotを監督・レビュー役に置く4AI体制のAIエージェント開発基盤です。GitHubを共通記憶にして、競争・分担・レビュー・統合までつなげます。

全体構成

📱 スマホ：指示・確認・最終判断
↓
🧠 Claude Code　｜　Google Jules　｜　OpenAI Codex
実装・独立比較
↓
🐙 GitHub：仕様・コード・ログ・PR・履歴を保存する共通記憶
↓
🛡️ GitHub Copilot：PRレビュー・競合確認・統合支援
↓
🤖 GPT：GitHub操作・統合・マージ・Actions・Pages公開を可能な範囲で完遂
↓
⚙️ GitHub Actions：テスト・検証・デプロイ
↓
🌐 GitHub Pages / PWA / API / 自動化へ展開

3つの運用モード

競争モード

同じ課題をClaude Code・Jules・Codexへ一斉に投げ、それぞれ独立に作らせます。設計・文章・UI・コード・テスト方法を比較して最良案を選びます。

チームモード

調査、設計、実装、テストなどをAIごとに分担します。1つが詰まっても別のAIで補えるため、止まりにくい開発になります。

監督モード

GitHub Copilotが新しいPRをレビューし、仕様違反、セキュリティ、スマホUX、古いブランチ、競合・重複を確認します。必要なら統合支援や小規模修正も行います。

GPT運用モード

可能なGitHub操作はGPTが積極的に引き取り、ブランチ、修正、PR、マージ、Actions、Pages公開、状態確認まで最後まで仕上げます。

GitHubが「記憶」になる

AI同士は会話履歴を直接共有できません。そこでREADME、AGENTS.md、PROJECT_SPEC、各AI向け指示、コード、コミット、PR、開発ログをGitHubに残します。次のAIはGitHubを読んで続きを理解できるため、会話をまたいでもプロジェクトを継続できます。

基本の流れ

スマホから目的を指示「何を作るか」を決める。
3実装AIへ一斉投入または役割分担Claude Code・Jules・Codexを競争またはチームで動かす。
各AIが専用ブランチで作業実装・テスト・自己レビューまで行う。
GitHubでPRとして集約成果と差分を見比べる。
Copilotが監督・レビュー仕様・安全性・競合・古い前提をチェックする。
GPTがGitHub運用を仕上げる可能な範囲で統合・マージ・Actions・Pages公開まで進める。
完成物を公開・次の開発へWeb、PWA、API、自動化などへ展開。

現在の役割分担

Claude Code

主力実装。大きな設計・コード作成・テスト・自己レビュー。

Google Jules

独立実装・比較。ClaudeやCodexとは別視点で同じ課題に挑戦。

OpenAI Codex

実装担当。コード変更、検証、GitHub向け成果物の作成。

GitHub Copilot

監督・レビュー・統合支援。3AIの成果をGitHub上で横断的に確認。

この仕組みの狙い

PCの前に張り付かない開発

スマホで指示と判断を行い、重い実装作業はクラウド上のAIエージェントに任せます。GitHubを中心にすることで、複数AIが同じ資産を扱えるようにします。

AIを「チャット相手」ではなく「開発チーム」にする

単発の質問で終わらず、仕様・履歴・成果物・レビューを蓄積し、次の作業へつなげることがこのシステムの中心です。
