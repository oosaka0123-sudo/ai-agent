# 2026-09-01

## Auto Site Onboarding 基盤

### 目的

今後WebサイトやPWAを追加しても、Google Vertex AI等の共通AI基盤を毎回手作業で
実装し直さず、control-planeへ登録するだけで自動オンボーディングできるようにする。

### 実装

- `scripts/register_project.py`
  - 新規プロジェクトを `projects/registry.json` へ安全に登録
  - slug / repository / URLを検証
  - media providerとauto_onboardを標準設定
- `scripts/onboard_projects.py`
  - 接続済みリポジトリへ `.ai-agent/project.json` / README をPRで配布
  - main直接push禁止
  - 冪等（同じ状態なら何もしない）
- `.github/workflows/register-site.yml`
  - スマホのworkflow_dispatchから新規サイト登録PRを作成
- `.github/workflows/auto-site-onboarding.yml`
  - registryがmainへ入ると自動検証
  - cross-repo token設定済みならtarget repoへonboarding PRを作成
- `tests/test_project_onboarding.py`
  - 登録、重複防止、対象選定、共通メディア設定をテスト
- `docs/AUTO_SITE_ONBOARDING.md`
  - 将来サイト追加時の運用と1回だけ必要な権限設定を文書化

### 安全性

- 認証情報はtarget repoへ配布しない
- cross-repo tokenはGitHub Secretのみ
- production / mainへ直接反映しない
- 既存の `max_parallel_projects=4` は同時進行数として維持し、登録サイト数は制限しない
