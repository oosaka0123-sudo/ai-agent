### IMPLEMENTATION

- `scripts/redeploy_google_media_mcp.sh` を追加した。
- helperは以下を強制する:
  - `main` ブランチで実行する
  - working treeがcleanである
  - local `main` と `origin/main` が一致する
  - root `Dockerfile` がGoogle Media MCP用である
  - activeなgcloud accountが存在する
- 既存Cloud Runサービスを `gcloud run deploy --source=.` で更新する際、`--set-env-vars` / `--set-secrets` / `--service-account` / `--allow-unauthenticated` / `--no-allow-unauthenticated` を意図的に指定しない。既存のservice設定・IAM・Secret Manager bindingを保持したまま、現在のsourceだけを再デプロイするため。
- deploy前後の `latestReadyRevisionName` を比較し、revisionが変わらなければ失敗扱いにする。
- deploy後に `/readyz` がHTTP 200かつ `ready=true` を返すことを確認する。
- CIへ `bash -n scripts/redeploy_google_media_mcp.sh` を追加し、外部GCPを叩かずshell構文を検証する。
