# 2026-08-30 — GitHub Copilot integration

## Goal

Add GitHub Copilot to the existing multi-agent development system without replacing Claude Code, Gemini/Jules, or OpenAI Codex.

## Design decision

Copilot's default role is **supervisor / reviewer / integration assistant**.
This avoids wasting parallel capacity by having Copilot duplicate tasks already assigned to Claude Code or Codex.

## Changes

- Added `.github/copilot-instructions.md` so Copilot has repository-wide operational instructions.
- Added `COPILOT.md` describing the team structure and human workflow.
- Defined PR review, branch isolation, conflict checking, mobile verification, security review, and no-direct-main rules.
- Defined that Copilot may implement small fixes or explicit implementation tasks on its own branch.
- Kept final merge decisions with the user.

## Verification

- Confirmed `.github/copilot-instructions.md` is the repository-wide instruction location supported by GitHub Copilot.
- Confirmed the existing repository already has root `AGENTS.md`, `CLAUDE.md`, `GEMINI.md`, and `CODEX.md` instructions.
- No application runtime code was modified, so no runtime regression was introduced by this change.

## Remaining external step

The GitHub account must have access to the desired Copilot features (for example Copilot code review or cloud agent) before those product features can execute these instructions.
