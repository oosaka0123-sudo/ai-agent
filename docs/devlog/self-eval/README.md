# docs/devlog/self-eval/ — AIごとの自己評価ログ

[`AGENTS.md`](../../../AGENTS.md) の「自己評価・品質保証」ルールに基づき、
各AIが自分の成果物に対して行った自己評価・修正・再テストの履歴を、
AIごとに時系列で記録する場所です。

`docs/devlog/YYYY-MM-DD.md`（日々の開発日記）とは別物です。
そちらは「その日やったこと」の日記、こちらは「品質保証プロセスの記録」です。

- `claude-code.md` — Claude Code の自己評価ログ
- `gemini-jules.md` — Gemini / Jules の自己評価ログ
- `codex.md` — Codex の自己評価ログ

**各AIは自分のログファイルにのみ追記してください。** 他AIのログファイルは
編集しません（[`guides/README.md`](../../../guides/README.md) と同じ独立性のルールです）。

## 1エントリの記録項目

- 対象（何を実装・変更したか、日付）
- 初回実装内容
- 自己評価結果（点数と問題点）
- 発見した問題
- 修正した内容
- 再テスト結果
- 最終自己評価
