# docs/devlog/ — 開発日記（Markdown）

ここには、1日ごとの開発作業を人間が読みやすいMarkdown形式でそのまま記録します。
ファイル名は `YYYY-MM-DD.md`（同じ日に複数回作業した場合は同じファイルに追記していく）。

- **役割**: 生の作業ログ・日記。振り返ったときに読み物として読める記録。
- 対して `data/devlog.json` は、同じ内容を **サイト表示用に構造化したデータ** です。
  Webサイト（トップページのタイムライン・検索・タグ絞り込み）は `data/devlog.json` を見ています。

つまり、1回分の作業が終わったら基本的に **両方に書く** 運用にします
（このMarkdownは人間が読む日記、JSONはサイトを動かすデータ）。

## 新しい日の記録を始める

1. [`_template.md`](_template.md) をコピーして `YYYY-MM-DD.md` を作成する。
2. テンプレートの各項目を埋める。
3. `data/devlog.json` にも同じ内容を1件追記する（フィールドの意味は
   [`../../data/README.md`](../../data/README.md) を参照）。

自動化のルール（Claude Codeなど、AIエージェントが開発作業のあとに毎回行うべきこと）は
[`../../AGENTS.md`](../../AGENTS.md) の「開発記録の自動記録ルール」にまとめています。
